Данное приложение позволит вам оптимизировать распределение бюджета с использованием метода аналитической иерархии.
Всё, что вам нужно - это просто ввести категории и степень их важности - система всё сделает сама.

Ссылка на веб-приложение: https://ila2201.github.io/kaplan/

Краткая инструкция:
1) Введите название нужной вам категории;
![image](https://github.com/user-attachments/assets/bc306612-14ca-4947-a8d6-2df92c6c5607)

3) Определите степень её важности;
![image](https://github.com/user-attachments/assets/8336224f-7c3f-4f9b-bb35-2ca35401559e)

5) Нажмите "Рассчитать";
![image](https://github.com/user-attachments/assets/039ab506-9e9c-4a00-aa92-6e76ce4dae67)

7) Получите результат. Он покажет долю для каждой категории;
![image](https://github.com/user-attachments/assets/984adf8b-837e-47bc-9e78-0f0cbc4b6578)

9) При желании, можете сразу ввести свободную сумму, которую уже сейчас можете распределить по категориям;
![image](https://github.com/user-attachments/assets/59441435-56ec-42a8-b329-e2302e0ee8fd)

11) Нажмите "Распределить" и получите готовый результат в рублях;
![image](https://github.com/user-attachments/assets/4629093d-ae7b-49fd-8595-3742784f1939)

Дополнительные возможности:
- Категорию можно удалить, нажав на красную кнопку с корзиной:
![image](https://github.com/user-attachments/assets/aa2d1719-711b-4972-86a8-238139ed08ac)

- Можно также очистить весь список категорий, нажав кнопку "Очистить всё":
![image](https://github.com/user-attachments/assets/c0e25883-1833-40ca-b4ad-3d094a90b3d6)

- Все добавленные категории сохраняются у вас в браузере! Вы сможете вернуться к сайту позже, всё сохранится.
